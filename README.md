# MirrorRepo-Core

Issues created in this repo will be mirrored to [PalmEmanuel/MirrorRepo-Internal](https://github.com/PalmEmanuel/MirrorRepo-Internal), as a presentation demo of how to use GitHub Apps in GitHub Actions for cross-repository automation.

Demos use [StageCoder](https://marketplace.visualstudio.com/items?itemName=EngstromJimmy.stagecoderVSCode) during the presentation.
